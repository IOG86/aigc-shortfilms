## 📋 人物形象一致性指南

### 保持角色跨镜头一致的方法

#### 方法1：图生视频（I2V）锁定
1. 先用上述提示词生成满意的角色设定图
2. 在海螺AI中使用"主体参考"功能上传设定图
3. 在提示词中强调：`strictly maintain the character design from the reference image`

#### 方法2：固定描述词模板
每个镜头的提示词中都包含以下固定描述：
```
[角色固定描述] + [场景描述] + [动作/情绪] + [黑神话风格词]
```

#### 方法3：负面提示词防止偏移
```
deformed face, extra limbs, missing fingers, facial asymmetry,
inconsistent character design, style change, color shift,
different clothing, missing armor details, wrong crown design
```

## 🔗 使用建议

1. **先生成角色设定图**：使用全身立姿提示词，生成每个角色的标准形象
2. **筛选最佳版本**：每个角色生成3-5张，选出最符合黑神话风格的
3. **作为参考图使用**：在海螺AI的"主体参考"功能中上传，确保视频生成时角色一致
4. **微调提示词**：根据生成结果微调描述词，重点保持铠甲、面部、毛发的细节一致
